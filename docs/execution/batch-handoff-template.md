# Batch Handoff Template

Use this template at the end of each implementation batch.

```md
# Batch: <name>

## Status
- done | partial | blocked

## What changed
- <repo artifact or code change>

## What is now true
- <new trustworthy fact>

## Checks run
- <command> -> <result>

## Remaining risks
- <risk>

## Exact next batch
- <next implementation batch>

## Blockers
- <only if blocked>
```
